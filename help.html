このサイトについてABOUT

27SSの各品番の納期とEC販売日を、カレンダーでまとめて見て、みんなで調整するためのサイトです。

  • 納期は、サクライの納期指定（オーダーシート）がもとになっています。
  • EC販売日は仮設定です。2月〜5月の隔週木曜を発売日にした「発売計画」を初期値として入れています。
  • 誰かが日付やラインを変えると、すぐ全員の画面に反映され、「変更履歴」に名前つきで残ります。
プロトタイプなので、「こうしたい」「ここが使いにくい」があれば、ぜひ木原まで教えてください。

はじめて開くときFIRST TIME

  1. カレンダーのURLを開きます：https://futa-ins.github.io/wt27ss/
  2. 申請画面が出たら、お名前とメールアドレスを入れて「アクセスを申請する」を押します。
  3. @ins.fm のアドレスなら自動で承認され、そのままカレンダーに切り替わります。
    それ以外のアドレスは木原が承認すると、開いたままの画面が自動で切り替わります。
次回からは、同じブラウザでURLを開くだけで入れます。別のパソコンやスマホで開くときは、承認時にメールで届くあなた専用のURLを使ってください（専用URLは他の人に共有しないでください）。

スマホで使うSMARTPHONE

  • iPhoneのSafariは、普通のタブで使えます（プライベートタブでなくて大丈夫です）。
  • カレンダーや表は横に長いので、横にスクロールして見てください。

アプリとして使う（ホーム画面に追加）

ホーム画面に追加すると、「WTカレンダー」のアイコンからアプリのように全画面で開けます。

iPhone

  1. SafariでカレンダーのURLを開く
  2. 画面下の共有ボタン（四角から上向き矢印）を押す
  3. 「ホーム画面に追加」→「追加」

Android：Chromeの右上「︙」→「ホーム画面に追加」（または「アプリをインストール」）

iPhoneでは、ホーム画面のアイコンから開いたときだけ、最初の1回だけ申請画面が出ます（Safariとは保存場所が別のため）。@ins.fm のアドレスで申請すればすぐ入れます。

シーズンを選ぶSEASON

開くと最初にシーズン選択の画面が出ます。年とシーズン（SS／FW）で絞り込み、展示会ブックの表紙のカードを押すと、そのシーズンのカレンダーが開きます。

あとから切り替えたいときは、画面上部の「シーズン変更」を押します。

今のところ中身が入っているのは2027SSです。

  • 納期近 納期から2週間未満のEC販売（入荷が間に合うか要注意）

絞り込み

ライン（アウトドア／ミリタリー／シティ／未設定）、表示（納期・EC販売・EC発注0の品番・品番のみ）のボタンと、検索窓（品番・商品名・カテゴリー）で表示を絞れます。

日付・ラインを変えるEDIT

カレンダーで動かす（ドラッグ＆ドロップ）

  1. 品番のカードを押したまま動かします（スマホは指で押したまま）。
  2. 置きたい日付の上で離すと、その日に移動します。
  3. 別の月に移したいときは、上の月ボタンの上で少し止めると月が切り替わります。

やめたいときは、日付のないところで離すか Esc を押します。

日付を入力して変える・ラインを変える

「Items」タブの表で、納期・EC販売日・ラインを直接変更できます。カレンダーとは常に連動しています。

変更は保存ボタンなしですぐ全員に反映されます。間違えたときは、同じ方法で元の日付に戻してください（「History」で元の日付を確認できます）。画面のデータは1分ごとに自動で最新になります。

商品ページ・カタログPRODUCT

商品ページ

カレンダーや表の品番をダブルクリック（スマホはダブルタップ）すると、商品ページが開きます。写真・品番・商品名・カラー・サイズ・上代（税込）・寸法・商品説明が見られます。

  • 「前の品番」「次の品番」で順番に見られます（パソコンは ← → キーでも）。
  • 「← 戻る」（または Esc）でカレンダーに戻ります。

カタログ

「Catalog」タブで、展示会カタログを1ページずつ縦に見られます。スマホは2本指で拡大できます。

困ったときFAQ

「読み込めませんでした」と出る

通信が不安定なときに出ることがあります。少し待ってからページを再読み込みしてください。

前は入れたのに、また申請画面が出る

ブラウザの履歴やデータを消すと、入るための情報も消えます。承認メールの専用URLから開くか、@ins.fm のアドレスでもう一度申請してください（自動で承認されます）。

前のURL（script.google.com）を開いてしまった

「新しいURLに移りました」と出るので、オレンジのボタンを押してください。ブックマークも新しいURLに変えておくと安心です。

「閲覧のみのため移動できません」と出る

アクセスが止められている可能性があります。木原に連絡してください。

FOR ADMIN — 木原向け

管理者向けADMIN

管理者として開く

管理者用URL（URLの最後に ?key=… が付いたもの）で開くと、申請なしで閲覧・編集でき、画面に「管理者」と表示されます。管理者用URLはメール「[27SSカレンダー] 共有URLと管理者URL」で届きます。人に共有しないでください。

アクセス申請の承認

  • @ins.fm のアドレスは自動で承認され、木原に「自動承認」のお知らせメールが届きます。
  • それ以外は「[27SSカレンダー] アクセス申請」メールの「承認する」「却下する」を押します（スマホでもOK）。

アクセスを止める

データのスプレッドシート「WT27SS_納期EC販売カレンダー_データ」の users シートで、その人の status を rejected に書き換えます。

画面の修正・毎シーズンの更新

  • Claude（プロジェクト「WT_27SSオーダーの集計」）に依頼します。新しい画面ファイルの用意・データの更新・テストまで行います。
  • GitHub（アカウント Futa-ins／置き場所 wt27ss）へのファイルの差し替えだけは、木原がファイルをドラッグ＆ドロップします（手順はその都度Claudeが案内）。
